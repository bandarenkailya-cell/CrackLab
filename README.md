## О проекте

CrackLab — веб-приложение для автоматического измерения трещин, возникающих при
индентировании (методе Виккерса) тонких покрытий и хрупких материалов.

По длине трещин и размеру отпечатка программа автоматически рассчитывает:

| Параметр | Обозначение | Единица |
|---|---|---|
| Микротвёрдость | H | ГПа |
| Коэффициент интенсивности напряжений | K | МН·м⁻³/² |
| Энергия разрушения (адгезии) | G | Дж |
| Удельная упругая энергия | Y | Дж |
| Глубина трещины | h | мкм |

Погрешность всех параметров оценивается методом **Монте-Карло** (N = 10 000 итераций, 95% ДИ).

## Возможности

- 🔍 **Автоматическое обнаружение** отпечатков индентора (HoughCircles) и трещин (лучевой анализ)
- 📊 **Расчёт свойств** для каждого скола отдельно и в целом по всему снимку
- ✏️ **Ручная корректировка**: нарисовать трещину, задать диагональ d или диаметр скола
- 📈 **Графики**: гистограмма длин, столбчатые диаграммы, средние по сколам
- 🌗 **Тёмная / светлая тема** по кнопке
- 🔬 **Масштабирование и панорамирование** изображения
- 📋 **Таблица Монте-Карло** с 95% доверительными интервалами

## 🚀 Запуск локально

### Требования
- Python 3.10 или новее
- pip

### Установка и запуск

```bash
# 1. Клонировать репозиторий
git clone https://github.com/YOUR_USERNAME/cracklab.git
cd cracklab

# 2. Установить зависимости
pip install -r requirements.txt

# 3. Запустить сервер
uvicorn main:app --reload --port 8000

# 4. Открыть в браузере
# http://localhost:8000
```

## 🌐 Бесплатный деплой

### Вариант 1 — Render.com (рекомендуется, самый простой)

1. Создайте аккаунт на [render.com](https://render.com)
2. Загрузите файлы в публичный репозиторий GitHub
3. На Render: **New → Web Service → подключить GitHub**
4. Render автоматически прочитает `render.yaml` и задеплоит

> ⚠️ На бесплатном плане сервис «засыпает» через 15 минут без запросов.
> Первый запрос после пробуждения может занять ~30 секунд.

### Вариант 2 — Hugging Face Spaces (без засыпания, 100% бесплатно)

1. Зарегистрируйтесь на [huggingface.co](https://huggingface.co)
2. **New Space → SDK: Docker**
3. Создайте `Dockerfile`:

```dockerfile
FROM python:3.11-slim
WORKDIR /app
COPY requirements.txt .
RUN pip install -r requirements.txt
COPY . .
CMD ["uvicorn", "main:app", "--host", "0.0.0.0", "--port", "7860"]
```

4. Загрузите все файлы. Port: **7860**

### Вариант 3 — Railway.app

1. [railway.app](https://railway.app) → **New Project → Deploy from GitHub**
2. Добавьте переменную: `PORT=8000`
3. Start command: `uvicorn main:app --host 0.0.0.0 --port $PORT`

## 📖 Как пользоваться

### Основной анализ

1. Нажмите **«Выбрать файл»** и загрузите микрофотографию
2. Укажите **длину стороны крестика** в мкм (по умолчанию 25 мкм)
3. Укажите **нагрузку на индентор P** в Ньютонах (обычно 0.98 Н для 100 г)
4. Нажмите **▶ Рассчитать**

### Корректировка результатов

| Инструмент | Как использовать |
|---|---|
| **✏ Трещина** | Кликайте для точек ломаной. Двойной клик — завершить. |
| **📐 Диагональ d** | Выберите скол → проведите линию по диагонали отпечатка |
| **⊙ Диаметр** | Выберите скол → проведите линию по краям зоны повреждения |
| **Удалить трещину** | Снимите галочку → кнопка «Удалить» |

### Навигация по изображению

| Действие | Управление |
|---|---|
| Зум | Колёсико мыши |
| Перемещение | Перетащить мышью |
| Сброс вида | Кнопка ⊙ Сброс |

## 🔬 Алгоритм обнаружения

Программа использует двухэтапный подход:

1. **Поиск отпечатков**: преобразование Хафа находит светлые круглые области
   (ореолы индентационных отпечатков). Проверяется, что центр темнее ореола.

2. **Поиск трещин**: из центра каждого отпечатка пускаются 360 лучей.
   Луч фиксирует тёмные пиксели (темнее 88% от локального фона).
   Соседние лучи группируются в сегменты — каждый сегмент = одна трещина.
   Граничные пиксели изображения автоматически игнорируются.

## 📐 Формулы расчётов

$$H = \frac{1.854 \cdot P}{d^2}$$

$$K = 0.016 \sqrt{\frac{E}{H}} \cdot \frac{P}{L^{3/2}}$$

$$G = \frac{0.627 H^2 h (1-\nu)}{E [1 + \nu + 2(1-\nu) H L^2 / P]^2}$$

$$Y = \frac{K^2}{2E}$$

где P — нагрузка (Н), d — диагональ отпечатка (м), L — средняя длина трещины (м),
E — модуль Юнга (Па), ν — коэффициент Пуассона, h = d/7.
